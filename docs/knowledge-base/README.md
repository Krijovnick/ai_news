# База знаний AI News Aggregator

Это единственный источник правды о том, **что программа должна делать**. Код подчиняется этим документам. Если код и база расходятся, править нужно то, что не совпадает с последней записью здесь.

## Как пользоваться

Перед любой доработкой прочитать этот файл и документы из оглавления, которые относятся к задаче.

Новое требование, режим, источник, правило фильтрации или формат сообщения записывать сюда **в том же изменении**, что и код. Не оставлять поведение только в чате или только в коде.

Секреты (токены, chat id, ключи API) сюда не писать. В базе только имена переменных и смысл настроек.

## Оглавление

| Документ | О чём |
|----------|--------|
| [program.md](program.md) | Назначение, режимы запуска, SQLite, источники, DeepSeek, веб, Telegram, конфигурация |
| [decisions.md](decisions.md) | Журнал новых требований и решений. Свежие записи сверху |

## Куда писать новое

- Поведение программы изменилось или уточнилось — править [program.md](program.md).
- Появилось отдельное решение («почему так», ограничение, отказ от идеи) — добавить запись в [decisions.md](decisions.md).
- Новый большой раздел (новый источник, новый режим) — новый файл в этой папке и строка в оглавлении выше.

Не дублировать одно и то же в нескольких файлах. В журнале — ссылка на раздел, где лежит само правило.

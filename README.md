# AI News Aggregator

Агрегатор новостей из Twitter, Google News, Hacker News и Reddit с отправкой дайджеста в Telegram (при необходимости — с краткими выжимками через LLM).

## Команды

Запускать из корня проекта (где лежит `main.py`), с настроенным `.env`.

| Команда | Что делает |
|--------|------------|
| `python main.py` | Полный прогон: сбор топовых новостей/постов/видео об ИИ за последние 7 дней из всех включённых в `.env` источников, фильтрация и отправка в Telegram. |
| `python main.py --youtube-only` | Режим только YouTube: топовые AI-видео за последние 7 дней (с фильтром по просмотрам), отправка в Telegram. |
| `python main.py --reddit-only` | Режим только Reddit: топовые AI-посты за последние 7 дней, отправка в Telegram. |
| `python main.py --google-hn` | Режим Google News + Hacker News: объединённый AI-дайджест только из этих двух источников за последние 7 дней. |
| `python main.py --test` | Проверка источников: по одному запросу к каждому включённому парсеру (Twitter, Google News, Hacker News, Reddit). Логи в консоль и в `logs/app.log`. |
| `python main.py --reddit-business` | Отдельный режим: только Reddit, список бизнес-сабреддитов из конфига; популярные посты за последние ~7 дней, без фильтра по ИИ-ключевым словам; отправка в Telegram как **Reddit Business Digest**. |
| `python scheduler.py` | Фоновый планировщик: периодически вызывает тот же сценарий, что и `python main.py` (полный агрегатор). Расписание задаётся в `scheduler.py` (по умолчанию 09:00 и 18:00). |
| `python test_aggregator.py` | Локальные проверки: конфиг, фильтры, Telegram (тестовое сообщение), быстрый опрос парсеров. |
| `python example_usage.py` | Демонстрационные сценарии из `example_usage.py` (не продакшен-запуск). |
| `python install.py` | Первичная установка: зависимости из `requirements.txt`, каталоги и т.п. |

## Переменные окружения

Секреты и флаги источников задаются в `.env`. См. `utils/config.py` для полного списка опций (Telegram, Reddit, провайдер суммаризации, `ENABLE_*` для источников и др.).

## Логи

Логи пишутся в каталог `logs/` (например `logs/app.log`).
